# Apple Website 2020

This was my earlier attempt at recreating Apple's website based on its 2020 design. I used HTML and CSS to recreate the layout, navigation bar, product sections, and overall appearance of the website.

## Technologies Used

- HTML
- CSS
- Font Awesome
- Google Fonts

## Features

- Navigation bar
- Product and promotional sections
- Product images and icons
- Footer

## How to Run

Open `index.html` in your browser.
